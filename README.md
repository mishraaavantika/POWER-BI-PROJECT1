# POWER BI PROJECT: HR ANALYTICS DASHBOARD (RETENTION ANALYSIS)

## 1. Project Overview

The project aims to help an organization to improve employee performance and improve employee retention (**reduce attrition**) by creating a HR Analytics dashboard.
The analysis aims to present the insights in the form of a dashboard conveying all information in the form of charts and graphs that are easy to understand and interpret results. 

## 2. Data Sources:

### HR ANALYTICS.CSV
The data file containing the raw data to be used for data analytics through **POWER BI**.

### THE DASHBOARD.PDF 
Contains the dashboard prepared for the data analayis of **ATTRITION RATES** according to "VARIOUS DATA CATEGORIES" given in raw dataset and added filters.
#### KPI's mainly are: 
1. Overall employees
2. Attrition and it's Rate
3. Average Age
4. Average Salary
5. Years at company 

## 3. Data Preparation

#### Identifying right data types
Selecting all the columns and using the Transform section of Power BI, we set **Detect Data Types** to correctly identify the data types for the columns. 

#### Removing Duplicates
Using the **Column Quality** of the Power BI **Power query** we remove the duplicates 

#### Removing Null values 
The null values are indentified and then removed from the datset from the column quality and then removing them through the power query.

#### Cleaning same data entries with different types entries 
Cleaning the data to select only one occurence of one categry and not in different ways like we have **Travel_rarely** and **TravelRarely** and make it to just one occurence of the same using **Find and Replace**.

#### Column Selection 
The data is analysed and the relevanyt columns are selected from the dataset that will be helpful in deriving the insights. The columns that are not of use are deleted from the dataset and some new columns are created for the analysis.
